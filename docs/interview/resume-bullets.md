# 简历项目描述

## 版本一：简历 2–3 行

负责开发法律合规 AI 助手，基于 `Spring Boot + Spring AI + LangChain4j + PGVector + Vue3` 实现统一多模型问答、RAG 检索增强、Agent 分析、异步合同审查与 PDF 报告生成。围绕 AI 工程化补齐复杂度路由、DeepSeek 不可用降级、流式进度反馈、统一 metadata 与评测数据集，提升系统可演示性与可信度。

## 版本二：问题—方案—指标—结果

- **问题**：法律 AI 场景中，简单问答、复杂分析、合同审查对模型能力和交互方式要求不同，单一路径难以兼顾效果、成本与稳定性。
- **方案**：设计统一聊天接口，支持 `BASIC / ADVANCED / ADVANCED_RAG / UNIFIED` 多模式；结合 RAG、Agent、SSE 与 PDF 生成完成问答—审查—报告闭环；补齐 fallback、metadata、认证流接口与评测资产。
- **指标 / 证据**：后端测试 `81/81` 通过，前端构建通过；统一响应稳定输出 `actualModel / routeReason / fallbackUsed / sourceCount / latencyMs`；交付 `24` 条问答数据、`6` 份知识库样例、`3` 份合同样例及固定结果模板。
- **结果**：项目从“有 AI 功能”提升为“可讲清楚架构、取舍、降级、验证与演示闭环”的 AI 应用工程项目。

## 面试口播版

我做的是一个法律合规 AI 助手，不只是接模型 API，而是做了统一多模型路由：简单问题走高级 RAG，复杂分析走 Agent，高级模型不可用时还能 fallback。前端可以直接看到实际模型、路由原因、是否降级和延迟，合同审查则支持流式进度和报告下载，所以这个项目比较能体现 AI 工程化能力。
